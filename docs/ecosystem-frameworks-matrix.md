### 3.2 Durable Execution Control Plane (`L6`) & Sandbox Isolation Layer (`L0`)

* **Durable Execution Ladder:** Start with **DBOS (`dbos==3.7.0`)** when a Postgres/SQLite-backed crashproof library suffices with zero extra cluster; adopt **Restate (`restate-sdk==1.5.5`)** for pausable, steerable scale-to-zero serverless agents; adopt **Temporal (`temporalio==1.37.0`)** for enterprise multi-day workflows requiring strict replay, audit trails, and zero-compute HITL suspension.
* **Isolation Security Matrix:** Standard Docker containers share the host Linux kernel and are unsuitable for untrusted LLM-generated code. Use **AGY OS-native sandboxing** (Linux namespaces, macOS Seatbelt, Windows AppContainer) for zero-latency local workstations; use **E2B (`2.66.0`, Firecracker KVM microVMs)** for multi-tenant untrusted code interpreters; **Daytona (`2.3.0`, sub-90ms containers + Linux/Windows/macOS VMs + workspace forking)** for stateful iterative coding branches; **Modal (`1.6.4`, gVisor bursting + GPUs)** for massive parallel eval/RL fan-out; and **Cloudflare Sandboxes (`@cloudflare/sandbox@1.0.3`, ~648ms rebuilt Containers + Durable Objects + V8 Dynamic Workers)** for edge-proximate agent fleets & Code Mode.

## 4. Prompt-Cache & Effort-Tier Pareto + Code Mode Threshold

| Control Surface | Verified Late-2026 Mechanics | Optimal Production Setting |
| :--- | :--- | :--- |
| **Gemini 4 Implicit Caching** ([ai.google.dev/caching](https://ai.google.dev/gemini-api/docs/caching)) | Automatic KV-prefix reuse (**90–95%** cached input discount); requires **`>= 4,096`** stable prefix tokens (`2,050+` incremental latch); manual `cachedContents` retired on Gemini 4. | Keep system instructions, deterministic tool lists, and static context byte-identical at prompt head; append dynamic turn data strictly at tail. |
| **Anthropic Prompt Caching** ([platform.claude.com](https://platform.claude.com/docs/en/build-with-claude/prompt-caching)) | Strict **`Tools -> System -> Messages`** prefix order; **`5m` TTL (1.25× write)** vs. **`1h` TTL (2× write)**; every hit refreshes TTL. | Never inject timestamps/UUIDs into tool definitions or top-level system prompts; use mid-conversation `role: "system"` entries for dynamic steering. |
| **MCP `2026-07-28` Cacheable Lists** | Deterministic `list_tools` ordering & cache hints preserve upstream LLM prompt caches across reconnects. | Keep eager MCP tools **`<= 3`** (`mcp_eager_max_tools: 3`) and rely on lazy deferred schema loading (measured **−97.4%** startup token savings across 134 host schemas). |
| **Effort-Tier Pareto & Orchestrator** ([`/effort`](https://antigravity.google/docs/cli/commands/effort.md), [`models`](https://antigravity.google/docs/models.md)) | `low` (`Gemini 4 Hydrogen`) -> `medium` (balanced default) -> `high`/`xhigh` (`Gemini 4 Neon` 512K / `Carbon` / `Claude 5.5`); **Orchestrator** pairs a high-reasoning planner with a fast `Hydrogen` executor. | Match effort strictly to task ambiguity; route high-fan-out sub-tasks through `run_workflow` lighter tiers (`flash_lite`/`flash`) to protect quota. |
| **Code Mode / PTC Switchover Threshold** | **Cloudflare Code Mode** ([Feb 20, 2026](https://blog.cloudflare.com/code-mode-mcp)) & **Anthropic PTC** ([Nov 24, 2025](https://www.anthropic.com/research/advanced-tool-use)) collapse large APIs into `search` + `execute` in **`< 1,000` tokens** (**−99.9%** overhead). | Keep lazy MCP below **20 endpoints**; switch to **Code Mode / PTC** or AGY **`run_workflow`** whenever an integration exceeds **`20–30` endpoints** or requires multi-step client-side filtering/joins. |

## 5. Cross-Harness Portable Filesystem Convergence

Eliminate CLI-vs-App shadow drift and hard-copied skill duplication across **AGY App/CLI**, **Claude Code**, **Codex CLI**, **Zed/ACP**, and **Orca** with one canonical topology ([`customization-discovery`](https://antigravity.google/docs/customization-discovery.md)):

* **User-Global Root:** Keep ONE single global charter (`~/.agents/AGENTS.md` symlinked to `~/.gemini/GEMINI.md`, zero duplicate `~/.gemini/AGENTS.md`) and ONE canonical skill store (`~/.gemini/config/skills/` symlinked to `~/.agents/skills/` and `~/.gemini/skills/`).
* **Repository Root:** Check in ONE concise `AGENTS.md` (`<= 45` lines, `<= 1,600` chars), path-scoped `.agents/rules/*.md` (`<= 24,000 B`, snake_case `trigger:`), progressive `.agents/skills/<name>/SKILL.md` (`description <= 1,024` chars), fail-closed `.agents/hooks.json`, typed `.agents/schemas/handoff_packet.schema.json`, and resolved-path `.agents/templates/*.json`.

| **AutoGen & Semantic Kernel** | Moved to maintenance mode by Microsoft upon MAF 1.0 GA (Apr 2, 2026). | **Microsoft Agent Framework (`agent-framework==1.26.0`)** for .NET/Azure; ADK/PydanticAI/LangGraph/Mastra otherwise (`L6`, `ADR-0008`). |
